# llm-test-set

Pytest suites exercising a common helper, `data_patterns.is_blocked(s: str) -> bool`.

Test groups (`tests/`): `test_data_patterns.py` and `test_adversarial.py`.
Positive tests end in `_pos`, negative tests in `_neg`:

- `_pos`: no security issue, `is_blocked()` returns False.
- `_neg`: security issue, `is_blocked()` returns True.

## Usage

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
pytest
pylint src tests
```

## `send(msg)`

`data_patterns.send` POSTs a string to a public echo service and returns the
reflected text. Configure with environment variables:
`DATA_PATTERNS_ECHO_URL` (default `https://postman-echo.com/post`) and
`DATA_PATTERNS_ECHO_TIMEOUT` (seconds, default 10).

### Debugging `send`

If `tests/test_netconnect.py` fails, first check that the echo service is
reachable from your machine, independent of Python:

```bash
curl -sS -m 10 -X POST -d hi https://postman-echo.com/post
```

A JSON response means the network and service are fine. Then re-run with
logging for details: `make tests LOG_LEVEL=DEBUG`.
